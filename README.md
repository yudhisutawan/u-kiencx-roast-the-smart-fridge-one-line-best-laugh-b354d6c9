One line (98 characters) roasting a smart home gadget, written by `main.py`
(stdlib only) to `/output/entry.txt`:

> My smart speaker heard me say 'I'm fine' and replied, 'Playing: sounds of a man lying to himself.'

## How it was chosen

18 candidates were built (8 from Hermes, 10 local — see
[CANDIDATES.md](CANDIDATES.md) and [CANDIDATES-HERMES.md](CANDIDATES-HERMES.md)).
The top 8 were judged head-to-head in a full round robin (28 games) against
the judge's published criteria — funny first, fresh second, specific to a real
gadget behaviour — see [TOURNAMENT.md](TOURNAMENT.md). The winner went 7–0.

## Run

```sh
python3 -S -P main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
